Owner: Engineering Lead; consulted/review perspectives: Product, Requirements, Architecture, Document Engineering, Security, Accessibility, QA, SRE, Editorial and Finance. | ID | Bounded decision / alternatives | Rationale and limit | Owner / validation |
|---|---|---|---|
| IMP-DEC-001 | React 19 + Tiptap 3 + Vite/TypeScript, using pinned OSS packages; alternatives: native contenteditable or a different editor | Real semantic editor with history/selection/IME engine rather than arbitrary HTML. No paid/cloud extensions or model calls. Lockfile records exact packages and integrity. | Frontend / browser and license inventory; independent accessibility/IME review still required. |
| IMP-DEC-002 | Python 3.14 WSGI application + SQLite WAL/FULL for the local milestone; alternatives: Node/Fastify/PostgreSQL or Python framework/PostgreSQL | Existing Python reference ecosystem and no mandatory external service make a deterministic local journey possible. This is a provisional local adapter, not replacement of production recovery/encryption decisions. | Architecture/SRE / transaction, process-exit and restore tests. PostgreSQL/replication remains a production gate. |
| IMP-DEC-003 | Cookie-based opaque hashed sessions and CSRF for same-origin browser | ARC-06 allows a cookie web adapter. No bearer token in local storage. Privileged publisher/finance/admin roles do not exist yet; no MFA bypass is introduced. | Security / HTTP tests; production session/proxy/MFA review required. |
| IMP-DEC-004 | Canonical AST v2 wraps a restricted ProseMirror semantic tree, with stable UUID block IDs, language/direction and explicit marks | v1 omitted inline marks and did not map directly to the editor; preserve original v1 examples, add a new version, reject unsupported nodes. No existing production data exists to migrate from v1. | Document/API / schema, Unicode and semantic tests; full round-trip corpus remains open. |
| IMP-DEC-005 | Portability jobs use immutable snapshots, private SQLite artifacts and bounded child conversion processes | Avoid public draft URLs and require current authorization on every download. No PDF/EPUB conformance, malware scan or kernel isolation is claimed. | Conversion/Security / job failure, revocation and actual DOCX/Markdown tests. |
| IMP-DEC-006 | Author Studio only is the active local release slice; later phases stay inventoried | User authorized incremental execution; governance explicitly defers advanced, unapproved research. No public catalog, rights release, AI or money operations are simulated as production functionality. | Product / next checkpoint, pending actual scope/market/vendor decisions. |
| IMP-DEC-007 | Apply the user's minimum 14-language requirement to the local interface using the total-speaker set, plus Persian; shared local JSON catalogs and metadata drive frontend/backend | Supersedes English-only ASM-002. Keep UI language/direction separate from manuscript data; persist device and nullable account preferences via migration 002. Simplified Chinese, standard written Arabic and `en-NG` Intl formatting for Pidgin are bounded implementation choices. No manuscript/model translation service or native language approval is claimed. | Product/Accessibility-i18n / DEC-011, multilingual-review.md; final aggregate and both browser suites passed; real language review remains a pilot gate. |

These are implementation assumptions for reversible local work, not actual legal, tax, finance or stakeholder approvals.
